### Laboratory Discussion

I integrated the Image widget into `newsfeed_card.dart` by using `Image.asset()` to display images from the project's assets folder. To make it dynamic, I added a boolean variable called `hasImage` and a nullable `imagePath` parameter. These determine whether a post should display an image or not. If `hasImage` is true and an image path is provided, the image will be displayed using `Image.asset()` with `BoxFit.cover` to properly fit the available space. If no image is provided, a placeholder widget will be displayed instead. I also used conditional statements to control what appears depending on the values passed to each post. This allows each newsfeed card to have its own image or remain text-only without needing a separate layout for each one.
